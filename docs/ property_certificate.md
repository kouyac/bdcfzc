## 📖 1. 证件基本信息与政策演变 (Document Background)

在进行国内不动产资产审计、金融抵押风控、RPA 自动化审批以及涉外法律翻译时，**房产证/不动产权证书**是最核心的法定凭证。

中国国内的房产资产证明主要存在两个跨时代版本，它们在版式和字段结构上存在显著差异，本项目均已实施结构化解构：
1.  **中华人民共和国不动产权证书（现行最新版）：** 自 2015 年 3 月 1 日起由自然资源部全面启用。其最大的视觉特征是**暗绿色封面**，实现了“房地一体化”登记，新增了全国唯一的 **28位不动产单元号** 并在内页右上角附有**全息条形码/二维码**。
2.  **中华人民共和国房屋所有权证（历史老版本）：** 2015 年前由建房部/住建部监制颁发。其视觉特征为**正红色封面**（俗称“老红本”），主要侧重于房屋本身的产权登记，土地所有权往往另发《国有土地使用证》。

### 🔍 基础元数据信息 (Metadata Profiles)
*   **监制机构：** 中华人民共和国自然资源部（新版） / 中华人民共和国住房和城乡建设部（旧版）
*   **版式规格：** 横版多行紧凑表格排版（通常为 A5 横向或折页版式）
*   **技术识别难点：** 跨行文本对齐、附图页（宗地图/分户图）的物理边界提取与比例尺校准、跨页所有人变更历史数据关联。

## 🗂️ 3. 核心字段元数据解构与 JSON 标签定义 (Field Schemas)

为了方便 AI 工程师、机器视觉（CV）研发人员以及智能化 RPA 系统建立标准的表单抽取模型，我们将房产证/不动产权证的核心字段解构为以下标准 JSON 键（Keys）：

| 序号 | 证件印刷字段 | 推荐标签名 (JSON Key) | 数据类型 (Type) | 版式特征与提取规范 (Extraction Rules) |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **不动产权证号 / 监字号** | `property_certificate_no` | String | 新版格式如“X（XXXX）XXXX不动产权第XXXXXXX号”；老版位于第一页顶部的红字监字号。 |
| 2 | **权利人 / 房屋所有权人** | `obligee_name` | String | 产权所有人姓名。OCR识别时需注意处理多位共同所有人名字并列的情况。 |
| 3 | **共有情况** | `ownership_status` | String | 常见值为“单独所有”、“共同共有”或“按份共有（通常附带比例，如50%）”。 |
| 4 | **坐落** | `property_location` | String | 房屋的完整物理详细地址。属于长文本字段，OCR 识别极易受分行和标点符号干扰。 |
| 5 | **不动产单元号** | `property_unit_number` | String (28位) | 新版特有的 28 位特长宗地/宗海代码，由数字与字母混排，是排他性的资产主键。 |
| 6 | **权利类型 / 权利性质** | `type_of_right` / `property_nature` | String | 明确土地（如出让、划拨）与房屋（如商品房、经济适用房）的产权合规属性。 |
| 7 | **用途** | `property_use` | String | 区分资产属性，如“城镇住宅用地 / 住宅”、“工业用地 / 工业厂房”。 |
| 8 | **面积** | `property_area` | Object / String | 包含土地分摊面积与房屋建筑面积，识别算法必须通过单位（㎡）精准归类两组数据。 |
| 9 | **使用期限** | `land_use_term` | String / Range | 主要是土地出让年限（如住宅 70 年，商业 40 年），格式通常为明确的起止日期对照。 |

## 🌐 4. 房产证/不动产权证高频核心术语英译对照 (Bilingual Glossary)

本术语表严格对接国际不动产评估、跨国资产审计、海外留学移民资产审查及涉外公证的标准行业术语：

*   **不动产权证书：** Real Estate Title Certificate / Property Ownership Certificate (New Version)
*   **房屋所有权证（老版房产证）：** Building Ownership Certificate / Property Ownership Certificate
*   **中华人民共和国自然资源部监制：** Supervised by Ministry of Natural Resources of the People's Republic of China
*   **权利人 / 房屋所有权人：** Obligee / Title Holder / House Owner
*   **共有情况：** Ownership Status
*   **单独所有：** Individual Ownership / Sole Ownership
*   **共同共有：** Joint Ownership
*   **按份共有：** Share-based Co-ownership
*   **坐落：** Location / Property Address
*   **不动产单元号：** Real Estate Unit Number
*   **权利类型：** Type of Real Estate Right
*   **权利性质：** Nature of Real Estate Right (e.g., Allocated/Granted)
*   **用途：** Use / Purpose of Use
*   **建筑面积：** Gross Floor Area (GFA) / Construction Area
*   **套内建筑面积：** Net Interior Area / Carpet Area
*   **土地使用权面积：** Land Use Area
*   **附记：** Note / Remarks

## 🛠️ 5. 计算机视觉 OCR 版式分析与算法训练难点 (CV/OCR Insights)

在研发自动化房产风控审批或智能 OCR 提取系统时，该类证件通常存在以下行业公认的技术攻坚难点：

1.  **跨行多重文本对齐与截断 (Multi-line Text Alignment & Wrapping)：**
    *   *难点：* “坐落”和“权利类型”等字段由于物理地址极长，在表格内往往会折成 2 行、3 行排版，且字体边缘经常与黑色的表格实体线重合粘连，导致传统的文本行检测器（Text Detector）切分错误。
    *   *解决方案：* 使用基于文本行线（Line-based）的几何投影或空间物理位置约束算法，或者利用深度学习的多模态文档大模型（如 **LayoutLMv3**）将断行文本在逻辑层面上完美合并为同一个键值对（Key-Value Pair）。
2.  **附图页比例尺提取与矢量化 (Blueprint Layout Vectorization)：**
    *   *难点：* 证书背面通常粘贴有“宗地图”和“分户图”（由各地房管局打印的平面蓝图），图片分辨率低，指北针、建筑边界红线、边界坐标数字极其微小模糊。
    *   *解决方案：* 引入专用图像分割网络（如 U-Net），将平面图区域单独切分出来（ROI Segment），利用霍夫变换（Hough Transform）结合 Canny 边缘检测提取房间多边形闭合边界，再由针对微小字符优化的 OCR 引擎专门提取比例尺和方向。
3.  **附记栏手写/机打混合体与后期盖章识别 (Mixed Font & Stamp Recognition)：**
    *   *难点：* 附记栏是房产证的“变动记录区”，经常有后期手工打印、人工手写备注（如“该产已抵押给银行”、“已办契税交纳”）以及五花八门的红色、蓝色金融机构印章干扰。
    *   *解决方案：* 在 OCR 模型中集成混合字体字典（Mixed Font Dictionary），利用空间注意力机制（Spatial Attention Mechanism）增强对模糊手写字体的鲁棒性；同时引入色调分离（HSV色彩空间过滤）技术，在不损伤字迹的前提下过滤或强化特定的公章层。
